# Musiques intégrées

Déposer les fichiers MP3 / OGG directement dans ce dossier, sans sous-dossier.
Le catalogue est généré par Vite, trié par nom, au démarrage et à la compilation.
Ajouter/remplacer un fichier en développement recharge la page et arrête l’audio.
Pour GitHub Pages, recompiler et redéployer après tout changement de fichiers.
Ajouter uniquement des créations personnelles ou des morceaux dont la licence
autorise la redistribution, accompagnés des crédits et de la licence.
Les fichiers de `public/` sont copiés tels quels dans le site publié.
Le lecteur encode automatiquement les noms dans les URL relatives à la base Vite.
